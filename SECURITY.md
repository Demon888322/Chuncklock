# Security policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting for this repository, if it is enabled. Otherwise, contact the repository maintainer through their GitHub profile and request a private disclosure channel. Include the affected version, impact, and reproduction details when safe to do so. Do not include real credentials or player data.

## Supported versions

Security fixes are prepared for the latest published version. Upgrade to the latest release before reporting a suspected issue.
